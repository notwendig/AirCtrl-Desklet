# AirCtrl-Desklet v2.00 Stable

Stand: 2026-09-25.

Diese Version bereinigt die Dokumentation und die Beispiele um persönliche Rechnernamen und Home-Verzeichnisse. Der Client verwendet standardmäßig `localhost:5680`. Auf einem anderen Rechner wird der Serverhost in den Verbindungseinstellungen oder mit `--server server` beziehungsweise `airctrl-client --host server` angegeben; `server` steht dabei für den tatsächlichen Hostnamen oder eine IP-Adresse. Die Versionsnummer der Programme lautet 2.00. Die Gerätefunktionen entsprechen v1.09.

Prüfungen und Grenzen: [VALIDATION.md](../../VALIDATION.md).
