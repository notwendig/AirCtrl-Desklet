# AirCtrl-Desklet 1.08

Version 1.08 vervollständigt die Trennung zwischen dem dauerhaften Server und
den Desktopclients. Eine still unterbrochene TCP-Verbindung wird jetzt ohne
Benutzeraktion erkannt; Tag und Nacht lassen sich mit einer einzigen
`between`-Regel beschreiben.

## Automatische Client-Wiederverbindung

- Das Desklet sendet im Leerlauf alle fünf Sekunden `ping` an den Server.
- Fehlt drei Sekunden lang das zugehörige `pong`, wird die nur scheinbar noch
  bestehende Verbindung verworfen.
- Nach der eingestellten Wiederverbindungspause verbindet sich der Client neu.
- Beim Verbindungsaufbau sendet der Server sofort Zustand, letzten bestätigten
  Gerätestatus und Lua-Zustand. Ein Schaltbefehl ist dafür nicht erforderlich.
- Der Integrationstest simuliert einen stillen TCP-Ausfall und bestätigt die
  Wiederverbindung ohne einen einzigen Geräteauftrag.

## Serverseitiges Lua-Skript

- Lua wird weiterhin ausschließlich im Qt-freien `airctrl-server` ausgeführt.
- Der Editor fordert beim Öffnen die serverweite Sperre an und erhält erst dann
  Skripttext und Revision.
- Speichern überträgt den Text zurück; der Server prüft und schreibt ihn atomar.
- Genau ein Client darf bearbeiten. Speichern, Abbrechen und der Abbruch der
  Eigentümerverbindung geben die Sperre frei.

## `between` für Tag und Nacht

```lua
airctrl.schedule {
    name = "tag/nacht",
    between = "07:00-22:00",
    days = {1, 2, 3, 4, 5, 6, 7},
    catch_up = true,
    set = { mode = "P", uil = "1" },
    outside = { mode = "S", om = "s", uil = "0" }
}
```

`set` wird am Beginn des Zeitraums verwendet, `outside` an seinem Ende. Bereiche
über Mitternacht werden ebenfalls unterstützt; der Endzeitpunkt gehört dann zum
folgenden Kalendertag.
