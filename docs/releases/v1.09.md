# AirCtrl-Desklet 1.09

Version 1.09 ergänzt eine serverweite manuelle Sperre für die Lua-Automatik.
Damit bleibt eine bewusst am Client gewählte Betriebsart erhalten, bis die
Automatik ausdrücklich wieder freigegeben wird.

## Verhalten

- Power, Betriebsart, Lüfterstufe, Zielfeuchte, Gerätefunktion und Timer sind
  automatikrelevante manuelle Einstellungen und aktivieren die Sperre.
- Licht/Anzeige (`aqil`, `uil`) und Kindersicherung (`cl`) verändern den
  Automatikzustand nicht.
- Die Power-Taste blinkt auf allen verbundenen Clients langsam, solange die
  Sperre aktiv ist.
- Ein Klick auf die blinkende Power-Taste hebt nur die Sperre auf. Er schaltet
  das Gerät nicht ein oder aus.
- Beim Freigeben wertet der Server den letzten bestätigten Gerätestatus sowie
  den zur aktuellen Uhrzeit gültigen Lua-Zeitplan sofort neu aus.
- Der Sperrzustand wird serverseitig gespeichert und übersteht einen Neustart.

Die vorhandene exklusive Lua-Editier-Sperre, TCP-Ping/Pong-Überwachung und
`between`-Unterstützung aus Version 1.08 bleiben unverändert.
